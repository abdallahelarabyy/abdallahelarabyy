## 📊 Data Analysis Projects

| Project | Business question & key finding | Tools |
| --- | --- | --- |
| [**Retail Sales & Profitability Analysis**](https://github.com/abdallahelarabyy/retail-sales-analysis) | Where does a retailer make and lose money? Four years of orders, $2.08M in sales. Furniture brings $675K in sales but keeps only a **2.8% margin**, and deep discounts are linked to losses. | Excel · SQL Server (T-SQL) · Power BI |
| [**Power BI Sales Analytics Dashboard**](https://github.com/abdallahelarabyy/powerbi-sales-analytics-dashboard) | How is a wholesaler performing? 26,397 sales lines cleaned in Power Query, modeled as a star schema, with 20 DAX measures and a 5-page report. Jan-May 2016 sales are **9.5% below** 2015, and **68 of 227 products make 80% of sales**. | Power BI · Power Query · DAX · Excel |
| [**Python Sales Analytics Dashboard**](https://github.com/abdallahelarabyy/python-sales-analytics-dashboard) | The same wholesale analysis rebuilt in code: a pandas cleaning pipeline (49 logged steps), Jupyter EDA, and a FastAPI + React dashboard. Totals **match the Power BI version to the cent**. | Python · pandas · Jupyter · FastAPI · React |
| [**Excel HR Analytics Dashboard**](https://github.com/abdallahelarabyy/excel-hr-analytics-dashboard) | What does a 689-employee workforce look like? An interactive dashboard with 9 PivotTables, 5 slicers and KPI cards. **7.5% of employees work 52% of all overtime hours**, and pay is not linked to job rating. | Excel · PivotTables · PivotCharts · Slicers |
